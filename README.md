# Азбука Я

Telegram-бот [@abcofmebot](https://t.me/abcofmebot) и мини-приложение: личный дневник, психологические тесты, портрет личности, отчеты и совместимость с друзьями.

## Устройство

- `diary/` — мини-приложение (React, Vite, Tailwind). Вкладки: Дневник, Тесты, Отчеты, Профиль.
- `backend/api/` — API для приложения (FastAPI): `main.py` собирает роутеры из `routers/` по разделам.
- `backend/telegram/` — бот (aiogram), `backend/scheduler/` — рассылки, автопродление Premium, вечерние напоминания о дневнике.
- `backend/pricing.py` — цены: Premium и стоимость функций с ИИ для оплаты с баланса.
- `backend/prompts/` — промпты ИИ, которые меняют без правки кода.
- `migrations/` — миграции Alembic, `run.py migrate` применяет их перед стартом.
- `design/` — исходники и варианты иллюстраций, которые не входят в приложение.

## Доступ

Premium — подписка без ограничений. Без нее функции с ИИ (ответ дневника, отчет, портрет, совместимость) оплачиваются с баланса; при первом открытии приложения начисляется демо-баланс.

## Запуск и деплой

`python run.py [migrate|api|bot|all]`. В продакшене каждый режим — отдельный контейнер (`docker-compose.yml`), деплой — push в `main`. Подробности — в `deploy/README.md`.
